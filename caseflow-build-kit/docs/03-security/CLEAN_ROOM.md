# Clean-Room Declaration

CaseFlow must be built from:

- public CData documentation and open-source examples;
- original code and visual design;
- repository-owned synthetic fixtures;
- publicly observable AIWorkbench architecture owned by the same repository owner;
- general engineering knowledge.

It must not include:

- employer or client code, schemas, prompts, data, screenshots, tickets, recordings, or internal documentation;
- private recruiter correspondence, compensation, benefits, or interviewer notes;
- copied CData UI, brand assets, or proprietary content;
- real source records.

Professional examples may be discussed verbally and in private interview preparation, but the public CaseFlow source and fixtures remain independent.

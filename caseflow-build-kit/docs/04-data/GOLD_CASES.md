# Gold Cases

1. **Canonical eligible credit** — carrier-caused delay >24h; $1,240 credit; Finance Manager approval.
2. **Customer-caused delay** — address unavailable/customer hold; no credit; customer explanation cites policy.
3. **Conflicting delivery events** — two terminal timestamps/cause mismatch; escalate; no proposal.
4. **Missing policy** — source unavailable or version absent; fail safe; no action.
5. **Duplicate execution** — valid approved proposal already applied; original receipt returned; no second credit.

Each case fixture includes required evidence, expected workflow state, disposition, amount, approval class, allowed actions, and expected failure category where applicable.

# Stage 2 — Director / Hiring Manager Lens

## Objective

Demonstrate that you can own a strategic engagement rather than only implement a ticket.

## Ask before presenting

> I built a compact synthetic engagement brief to make the discovery and architecture approach concrete. Would a three-minute walkthrough be useful?

## Three-minute order

1. Customer objective and why the current process fails.
2. Discovery questions and source authority.
3. Architecture: CData connectivity, deterministic control, human approval, replay/live boundary.
4. Acceptance criteria and phased rollout.
5. Why the result becomes a reusable pattern.

## Main point

> I would not start by promising an autonomous dispute agent. I would first establish what “resolved” means, which systems own each fact, what the agent may read or do, how approval works, what failure looks like, and how success is measured.

## Professional bridge

Use verified examples:

- external logistics integrations for source contracts and operational reliability;
- governed reporting for approved data surfaces and authorization;
- Story Runner Lite for turning a useful individual workflow into a reusable governed platform;
- integration test harness for repeatable deployment validation.

## Likely questions

- Why FDE now?
- How would you run the first customer workshop?
- What do you do when the customer objective is vague?
- How much do you build versus advise?
- How do you avoid bespoke consulting?
- What would you do in the first 30/60/90 days?

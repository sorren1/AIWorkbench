|---|---:|---|
| Gold-case disposition agreement | 5/5 | deterministic expected-result assertions |
| Required evidence completeness on canonical case | 100% | schema validation and required-fact checklist |

| Unauthorized live/simulated writes blocked | 100% | negative tests across workflow states |
| Duplicate credits after replayed execution | 0 | idempotency ledger assertions |
| Partial failures correctly classified | 100% of injected cases | failure-injection suite |
| Public replay network dependencies | 0 external requests | browser/network assertion |
| Public secrets and real identifiers | 0 | secret scanner and synthetic-data validator |
| Direct route availability | 4/4 | deployment browser tests |
| Existing pages linking to CaseFlow | 0 | static link and browser tests |
| Accessibility | 0 serious/critical axe findings | automated + keyboard review |
| Strategy tour | ≤3:00 | rehearsal timing |
| Technical tour | 6:00–7:00 | rehearsal timing |
| Operations tour | ≤5:00 | rehearsal timing |
| Product tour | ≤3:00 | rehearsal timing |

# Non-Goals

CaseFlow v1 does not attempt to:

- replace a CRM, ERP, billing, shipment, support, or case-management system;
- handle real customer or employer data;
- expose an anonymous or public execution endpoint;
- provide full multi-tenant identity, workspace isolation, enterprise RBAC, or SSO;
- prove production availability, throughput, or incident response at customer scale;
- train, fine-tune, or benchmark a foundation model;
- use RAG for structured transactional data;
- automate approval of consequential financial actions;
- support arbitrary user-authored SQL or arbitrary tool invocation;
- implement every dispute type;
- reproduce CData product UI or branding;
- add navigation from the existing portfolio or Workbench;
- deploy the local Python service to Vercel in the initial release.

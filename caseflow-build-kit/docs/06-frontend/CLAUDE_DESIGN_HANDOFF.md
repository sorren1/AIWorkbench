# Claude Design Handoff Contract

T08 and T09 must produce files under `deliverables/design/`:

- `design-principles.md`
- `tokens.json`
- `component-specs.md`
- `strategy-view.md`
- `technical-view.md`
- `operations-view.md`
- `product-view.md`
- `responsive-and-accessibility.md`
- `interaction-state-matrix.json`
- optional static mock images or HTML prototypes under `deliverables/design/prototypes/`

Every component specification must include:

1. purpose;
2. content fields;
3. visual hierarchy;
4. interaction and keyboard behavior;
5. states and errors;
6. responsive behavior;
7. accessibility notes;
8. implementation acceptance criteria.

The design handoff may not change source authority, workflow rules, claim labels, route names, or public/live boundaries.

# Fixture Guide

All data in this directory is synthetic and safe for public use after validation.

- `source-data/` imports into baseline CData-connected sources.
- `postgres/` creates finance/operations tables.
- `policy/` is the versioned policy fixture.
- `gold-cases/` defines deterministic evaluation cases.
- `replay/` is an initial contract-complete planning replay; it must be regenerated by the implementation before release.

Do not label the initial replay as live-validated. `capability-summary.json` explicitly says `SIMULATED` until T03/T25 replace it.

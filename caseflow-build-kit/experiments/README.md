# Experiments

Experiments isolate official CData starter code and optional tooling from the main CaseFlow runtime.

- `cdata-python-sdk-spike/` — created in T04.
- `cdata-agent-scaffold/` — generated in T06.
- `cdata-cli-spike/` — documented in T07.

Every experiment must preserve upstream license/notice files, use ignored secrets, and produce a conclusion about reusable patterns. An experiment is not automatically a production dependency.

# Deliverables Workspace

Agents write task outputs here. This directory intentionally contains only templates/readmes in the initial kit.

Expected subdirectories:

- `completion-reports/`
- `design/`
- `evidence-spikes/`
- `interview/`
- `captures/`

Do not place secrets or raw live evidence here. Raw live evidence belongs in the ignored `.caseflow-live-evidence/` directory in the host repository.
